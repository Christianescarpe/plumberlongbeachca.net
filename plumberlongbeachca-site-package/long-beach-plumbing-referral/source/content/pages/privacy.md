This preview is a set of static pages. It does not include an analytics script, an advertising pixel, a chat tool, or a form. Loading a page does not ask you for a name, a phone number, or an address. The site does not set its own tracking cookies. Your browser and the host that eventually serves the files may still keep ordinary server logs. This preview is meant to be opened locally or on a private host, not published.

If someone later turns on analytics or call tracking, this notice is wrong until it is rewritten and reviewed. Do not treat the paragraphs below as a description of tools that are already installed. They describe the limit now, and the questions a production launch would have to answer first.

## If a real phone line is added {#if-a-phone-line-is-added}

A telephone call reveals your number to the phone network. It would also reveal whatever you say to the referral operation and to any provider who is connected. That is inherent in a phone call. It is not a web form. The address and the symptom you speak would be used to decide whether a provider accepts the work and to let that provider contact you about the job. They would not be used, on this model, to build a public testimonial.

Recording and transcription are not enabled. California is an all-party-consent state for confidential conversations. This operation is not relying on a recording feature, and it should not add one without a privacy review, a script that announces it, a retention limit, and a decision about who can listen. None of those decisions have been made. Do not assume a call is recorded.

What has not been chosen, and therefore cannot be promised: the vendor, how long a call detail record would be kept, whether a recording would exist, who inside an operator’s shop could open it, and whether a lead network would receive the audio or only a disposition. Those blanks are launch gates. Inventing a “we keep data for 90 days” line would be fiction.

## Who would receive a connected call {#who-would-receive}

On the intended model, recipients are the phone carrier, the referral operator, and the provider who accepts the introduction. A network that routes or pays for qualified calls might see disposition data. No such network is named on the public site, and no payout figure is published. You would not be asked to pay this website for the plumbing work. Payment for the job, if you hire someone, goes to the contractor under their contract.

This preview does not sell mailing lists, because it does not collect them. It does not honor web-form deletion requests, because there are no web-form records. A request about a future call would go to the operator once an operator is identified. That identity is not published yet. See [about](/about/) and [how referrals work](/how-referrals-work/).

Children are not the audience. Do not use the site to send a child’s information. There is nowhere to send it.

:::faq
Q: Does the site store what I type?
A: There is nowhere to type it in. The pages have no form and no analytics tag. A hosting company might log an IP address if the files are put on a server. Do not send project details to an email address this site does not publish.

Q: Will a future call be recorded?
A: Not under the current decision. Recording is off, and it stays off until consent, retention, and access rules are written down and this page is updated. A long call is not evidence of a recording. If you ever hear an announcement that a call is recorded, that announcement has to match a policy that names the vendor. It does not match this preview.

Q: Can I ask you to delete a lead?
A: There is no lead file from this website to delete. If a live line later creates call records, the operator identified on the about page would be the party to ask, and the privacy notice would have to say how. Until that operator is published, there is no inbox for a deletion request. Utility calls you place yourself are outside this site’s records.
:::
